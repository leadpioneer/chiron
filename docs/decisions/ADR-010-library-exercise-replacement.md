# ADR-010 — Замена упражнения из полной базы

- **Статус:** принято; реализовано и задеплоено 27.10.2026 (`5d0a8a8`)
- **Дата:** 27.10.2026
- **Владелец:** автор проекта
- **Связанные документы:**
  [`ADR-008`](ADR-008-user-control-and-corrections.md),
  [`v1-decisions`](v1-decisions.md)

## Контекст

Короткий список замены состоял из 17 курируемых вариантов. В базе
`exercise_library` лежит 876 упражнений, но они не были доступны для замены.
Нужно выбирать любое упражнение из базы, а не только из короткого списка, и
сохранять новую схему в будущих тренировочных днях того же типа.

## Решения

### 1. Поиск по полной базе

- Новый `GET /api/exercises/search?q=…` ищет по `exercise_library.name`,
  `name_ru` и `aliases_ru`, минимум 2 символа, до 20 результатов.
- В модалке замены остаётся короткий список и добавляется поиск по базе.
- Результат показывает русское название, оборудование и категорию.

### 2. Создание упражнения из базы

- При выборе упражнения из базы сначала ищется существующий
  `exercise_variants.library_id`.
- Если варианта нет, создаются `exercises` и `exercise_variants`:
  - slug `lib_<library_id>`, имя `name_ru ?? name`;
  - `library_id` связывает вариант с базой;
  - load mode выводится из названия/оборудования: `EXTERNAL`, `ASSISTED`,
    `BODYWEIGHT` или `BODYWEIGHT_PLUS`;
  - increment 2.5 кг, `pair=false`, `sides=1`.
- Создание варианта пишет `LIBRARY_EXERCISE_ADDED` с actor и subject.
- Для основного блока разрешены только compound-упражнения не из
  stretching/cardio. Для подсобных — любое упражнение из базы.

### 3. Сохранение схемы

- Замена создаёт новую версию плана: копируются все блоки и назначения,
  выбранное упражнение подменяется, нагрузка обнуляется для калибровки.
- Все `PLANNED` и `IN_PROGRESS` сессии цикла переводятся на новую версию;
  сохранённые подходы, пропуски и незавершённые рекомендации переносятся на
  новые prescription id. Завершённые сессии остаются на старых версиях.
- Будущие сессии с тем же `session_key` получают новое упражнение; другие типы
  тренировок не меняются.
- Схема действует в текущем цикле. Следующий цикл по-прежнему строится из
  шаблона; перенос изменений в шаблон — отдельная задача.

### 4. Границы

- Нельзя заменить упражнение, по которому в текущей тренировке уже есть
  подходы.
- Свободного текста для названия нет: источник — база упражнений.
- Новый вариант глобальный и переиспользуется при следующем выборе того же
  упражнения.
- Добавление и удаление упражнения в схеме — отдельный срез,
  [`ADR-011`](ADR-011-add-remove-plan-exercises.md).
- Автоматическая отмена замены не вводится: откат — новой версией плана.

## Последствия

- Новый API поиска и создание `exercise_variants` on demand.
- В модалке замены два пути: короткий список и полная база.
- Замена из базы проходит тест на сохранение в будущих днях того же типа.
- Новых миграций нет: используются существующие таблицы.
- Проверки: 145 unit, 48 e2e, typecheck, build.
