# Техническая сессия 24.10.2026

## Цель

Собрать рабочий сквозной контур Chiron V1, проверить его на локальной базе и
зафиксировать решения для следующего этапа.

## Что сделано

### Каркас и домен

- Монорепозиторий npm workspaces:
  - `apps/web` — Next.js 16 App Router, UI и REST API;
  - `packages/core` — чистый TypeScript: метрики, прогрессия, safety,
    сопоставимость, шаблон, расписание, парсер;
  - `packages/contracts` — Zod-схемы API;
  - `packages/db` — Drizzle schema, клиент, миграции, seed.
- 73 доменных теста: метрики, тоннаж, границы, safety, прогрессия,
  независимость основных движений, календарь, шаблон, golden-кейсы парсера.
- `npm run typecheck`, `npm test` и `npm run build` проходят.

### Пользовательский контур

- Email magic link, Telegram Mini App `initData`, демо-вход для разработки.
- Онбординг: профиль, вес, рост, приблизительный процент жира, стаж, цель,
  перерыв, схема тренировок, варианты, подсобка, эстетика, стартовые нагрузки.
- Один шаблон «Тяни / Толкай»: два основных движения в каждой тренировке,
  необязательная подсобка, эстетика.
- Две схемы двухдневного сплита:
  - «через день» — 28 сессий за 8 недель;
  - «треня–отдых–треня–отдых–отдых» — 23 сессии.
- Цикл на 8 календарных недель; завершение по минимуму 8 экспозиций на
  основное движение; переход к следующему циклу.
- Дневник: подходы, вес, повторы, RIR, техника, боль, таймер отдыха.
- Быстрый ввод текста с локальным парсером и опциональным Gemini.
- Недельный чек-ин: сон, стресс, мотивация, болезненность.

### План и решения

- Детерминированные действия: `PROGRESS`, `HOLD`, `LOCAL_REDUCE`,
  `DELOAD`, `PAUSE`.
- Независимая прогрессия основных движений и подсобки.
- Copy-on-write версии плана; каждое изменение связано с решением и audit.
- Подтверждение, правка, частичное принятие и отклонение рекомендации.
- Safety-гейты: красный флаг останавливает тренировку, yellow блокирует
  повышение.
- История по упражнениям, audit-журнал, экспорт JSON, удаление аккаунта.

### Данные и окружение

- PostgreSQL 16-совместимая схема, Drizzle, миграции `0000` и `0001`.
- 876 упражнений из `RU-free-exercise-db` импортированы в `exercise_library`;
  все 16 вариантов шаблона связаны с библиотекой, инструкции показываются в
  карточке упражнения.
- Для локального запуска без Docker добавлен `npm run db:dev`: встроенный
  PostgreSQL в `~/.chiron/pgdata`, миграции и seed.
- Данные БД вынесены за пределы проекта, чтобы watcher Next.js не реагировал
  на WAL и не перезагружал страницу.

## Найденные и исправленные проблемы

1. Старое название шаблона «2 раза в неделю» противоречило новым схемам —
   переименовано в «Тяни / Толкай», шаблон пересэмплирован.
2. Dev-индикатор Next.js перекрывал интерфейс — отключён
   (`devIndicators: false`).
3. В настройках опыт и цель отображались как `RETURNING` / `BOTH` — добавлены
   русские подписи.
4. В подзаголовке «Сегодня» показывалась ISO-дата — убрана.
5. Тест переноса/пропуска был нестабилен из-за гонки с запросом — тест теперь
   ждёт ответ API; продукт корректно возвращает `409`, если сессия уже начата.
6. Hydration mismatch от Telegram WebApp script — подавлен через
   `suppressHydrationWarning` на `<html>`.

## Принятые решения и отклонения

- Вместо pnpm используются npm workspaces: в окружении не удалось активировать
  pnpm, границы пакетов сохранены.
- Вместо Docker для локальной разработки используется встроенный PostgreSQL;
  Docker Compose остаётся вариантом для эксплуатации.
- Следующий цикл пока начинает с текущих весов и сбрасывает целевые повторы;
  автоматический шаг вверх не применяется.
- Перенос тренировки и пересмотр цикла после длинной паузы зафиксированы в
  [`ADR-002`](../decisions/ADR-002-reschedule-and-cycle-review.md), но ещё не
  реализованы. Это P0 следующей сессии.

## Текущее состояние

- Приложение запускается на `http://localhost:3000`.
- `npm run db:dev` поднимает локальную БД, применяет миграции и seed.
- `npm run dev` запускает Next.js.
- В `.env` локально указан порт `55432`; для Docker нужно вернуть `5432`.
- В репозитории нет git-коммитов: сессия работала в каталоге без git.

## Риски и технический долг

- Полный 8-недельный цикл не прогнан; проверены только создание цикла,
  отдельные сессии и граничные API-сценарии.
- Редактирование рекомендации и частичная разгрузка покрыты кодом, но не
  E2E-тестами.
- Нет CI и Playwright-тестов в репозитории; текущие сценарии лежат во временной
  папке.
- Telegram и Gemini проверены только в fallback-режиме, без живых ключей.
- Не реализованы перенос даты и пересмотр цикла после длинной паузы.
- Не реализованы офлайн-очередь, настройки оборудования и полный
  accessibility-аудит.
- UI недельного чек-ина на мобильном требует проверки перекрытия нижней
  навигацией.
