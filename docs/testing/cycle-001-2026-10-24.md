## Найденные и исправленные проблемы

| Проблема | Исправление |
|---|---|
| Название шаблона всё ещё «2 раза в неделю» | Переименовано в «Тяни / Толкай», шаблон пересэмплирован в БД |
| В dev-режиме поверх интерфейса висел индикатор Next.js | `devIndicators: false` |
| В настройках опыт и цель показывались как `RETURNING` / `BOTH` | Русские подписи |
| В подзаголовке «Сегодня» показывалась ISO-дата | Убрана; осталась локализованная дата тренировки |
| Тест skip был нестабилен: старт успевал раньше skip | Тест ждёт ответ `/skip`; продукт корректно возвращает `409`, если сессия уже начата |

- Полный 8-недельный цикл и переход к следующему циклу через 28/23 сессии.
- Редактирование рекомендации (изменение веса/повторов) через UI.
- Живые Telegram `initData` и Gemini: нет ключей; проверен только локальный fallback.
- Офлайн-очередь подходов (не реализована).
- Настройки оборудования (сиденье/фиксатор) — не вводятся.
- Отдельного UX для переноса даты нет; есть только пропуск.
- Полный accessibility-аудит (контраст, screen reader) не проводился.
